# Privacy and public-repository hygiene

The public author name is `0xAllow`. Example IP addresses are private LAN examples, not identifiers for a public host. The executable may expose Go compiler and module metadata.

Before publishing, inspect every commit's author name and email (`git log --format=fuller`) and set your repository-local Git identity to your desired handle and GitHub-provided noreply address. Rewriting files does not remove personal data from older commits.

Do not publish user-specific state directories, transfer receipts, trusted-device records, test files with real content, or pre-existing Git histories without reviewing them.
